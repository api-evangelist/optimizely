# Optimizely

> Optimizely is a digital experience platform (DXP) combining Web and Feature Experimentation,
> Content Management (CMS), Content Marketing Platform (CMP), Commerce (Configured Commerce and
> Commerce Connect), the Optimizely Data Platform (ODP) customer data platform, Optimizely Graph,
> Campaign (email/omnichannel), Content Recommendations and the Opal AI agent layer. Optimizely
> publishes an RFC 9727 API catalog, 28 OpenAPI documents, a per-product llms.txt for every
> product area, and three OAuth-protected remote MCP servers.

This index is generated by API Evangelist from the Optimizely developer surface probed
2026-08-13. Optimizely serves NO llms.txt at the docs host root (404) — it publishes one
llms.txt per PRODUCT instead. Those provider-published files are the authoritative index and
are captured verbatim alongside this file.

## API discovery

- [API catalog (RFC 9727)](https://docs.developers.optimizely.com/.well-known/api-catalog): Two-level linkset naming every published OpenAPI document
- [Developer documentation](https://docs.developers.optimizely.com/): Product-scoped ReadMe portal; every page is also served as markdown by appending .md
- [Support help center](https://support.optimizely.com/): Product support and MCP server setup articles
- [Status page](https://status.optimizely.com/): Statuspage.io, JSON at /api/v2/status.json
